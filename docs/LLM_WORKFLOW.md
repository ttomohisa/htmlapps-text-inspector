# LLM workflow

1. Read `AGENTS.md` and `APP_SPEC.md`.
2. Edit `src/index.template.html` and relevant docs only.
3. Keep translations synchronized.
4. Run `scripts/check-repository.ps1` on Windows.
5. Review `dist/build-size-report.json`.
6. Test readable and self-extract releases with network disabled, at narrow mobile and desktop widths.
